Module Owner and Lecturer for [CSC1035 Introduction to Embedded Systems](https://www.qub.ac.uk/courses/undergraduate/computer-science-meng-g402/#modules).

This module introduces the foundations of embedded systems, including basic electronics, Arduino, C programming, memory and pointers, compilation and linking, state machines, registers, interrupts, ADC, and PWM.
