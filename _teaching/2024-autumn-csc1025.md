Lecturer for [CSC1025 Procedural Programming](https://www.qub.ac.uk/courses/undergraduate/computer-science-meng-g402/#modules).

This module introduces the fundamentals of procedural programming, including primitive data types, program control structures, functions, arrays, file I/O, error handling, pseudocode, and algorithm development.
